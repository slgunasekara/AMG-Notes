Structure: Course (e.g. HDSE) → Semester (e.g. Semester 1) → Module (e.g. OOP) → each module has its own Resources (notes/docs), PDF / Drive links (own card style) and Lecture Repo (GitHub, people cards). Use Add to add things, Structure to rename/hide/delete/reorganise anything, Page Text for titles, and GitHub Sync to publish.

Where to add

Pick the Course → Semester → Module first — the three add-forms below all target this module.

Add a resource (note / doc / link)

Add a PDF / Google Drive link

Own card style with the Drive icon — shows in this module's "PDF / Drive" row.

Add a GitHub repo (Lecture Repo)

Adds a repo under a person's card in this module's "Lecture Repo" row — creates the person if new.
